# Logo assets

Adapted from the project owner's supplied logo. The original is retained as `source-logo.jpg`.

| File | Dimensions | Use |
| --- | --- | --- |
| `logo-readme.png` | 640×360 | Full wordmark in the repository README, displayed at 480 pixels wide |
| `icon-small.png` | 64×64 | Small skill icon using the green M |
| `icon.png` | 256×256 | Larger skill icon using the same M |
| `social-preview.png` | 1280×640 | Repository social-share preview; under GitHub's 1 MB custom-upload limit |

Exports crop the supplied raster artwork and preserve its lettering and colours. The icon isolates the M and adds dark padding so adjacent letters are not visible. No new typeface or lettering is substituted. The larger outputs inherit the resolution limits of the original JPEG.

The README and skill interface reference their assets directly. To activate the social preview, upload `social-preview.png` in **Repository Settings → General → Social preview**. Storing this file or displaying a README logo does not configure GitHub's Open Graph image; no API setting change is implied.
